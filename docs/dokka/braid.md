# Module braid

Core Braid integration for delegated lists built on AndroidX `ListAdapter`.

# Package io.github.k1een.braid

Provides type-safe delegate routing, ViewBinding and holder-local state APIs,
per-delegate identity, content comparison and payload rules, RecyclerView
lifecycle routing, strict missing and overlapping delegate diagnostics, and
compatibility with isolated `ConcatAdapter` view types.

`DelegateRegistry` exposes the same routing and diff semantics for advanced
custom adapter integrations.
