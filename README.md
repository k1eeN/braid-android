# Braid

Braid is a type-safe delegate system for AndroidX `ListAdapter`.

The project aims to simplify production-ready Android lists while preserving
the standard `ListAdapter`, `DiffUtil`, and `RecyclerView` architecture.

## Status

Braid is currently under active development. The public API is not stable yet.

## Modules

- `braid` — library module.
- `sample` — sample Android application.

## Planned features

- Type-safe adapter delegates
- Per-delegate diffing and payloads
- ViewBinding support
- Stateful ViewHolders
- Paging 3 support
- Nested lists
- Delegate testing utilities
